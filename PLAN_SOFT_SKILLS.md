# План реализации динамических навыков (Soft Skills)

## 1. Концепция
Система разделяется на две категории навыков:
* **Hard Skills (Встроенные):** Написаны разработчиком, вкомпилированы в DLL (например, получение видов, чтение параметров, базовые системные вещи).
* **Soft Skills (Динамические):** Создаются самим агентом по запросу пользователя. Представляют собой скрипты, которые сохраняются локально, компилируются/интерпретируются в рантайме и динамически регистрируются в пайплайне LLM.

## 2. Архитектура хранения и регистрации

1. **Директория хранения:** `%AppData%\RevitAIClient\SoftSkills\`
2. **Формат хранения:** Каждый навык — это отдельный файл (например, `.json`), содержащий:
   * `Name` (Имя функции для LLM)
   * `Description` (Описание функции)
   * `Schema` (JSON-схема аргументов)
   * `Code` (Сам код скрипта на C#)
3. **Регистрация при запуске:** При открытии плагина, система читает папку `SoftSkills`, парсит файлы и создает для каждого экземпляры-обертки `DynamicSkillAdapter : IRevitSkill`, которые добавляются в общий список `_skills` в `ChatWindow.xaml.cs`.

## 3. Движок исполнения (Execution Engine)

Выбран вариант **Динамической компиляции C# через `CSharpCodeProvider` (CodeDom)**.
Использует встроенный в .NET Framework механизм компиляции текста в сборку (Assembly) прямо в памяти.
* **Плюсы:** 
  * 0 внешних зависимостей (используется `System.dll`).
  * Полный доступ к Revit API, типизация, высокая скорость работы после разовой компиляции.
  * Тот же язык, что и у плагина (C#).
* **Ограничения:** 
  * Поддерживает синтаксис только до C# 5.0 (нет интерполяции строк `$"{}"`, нет паттерн-матчинга).
  * Для обхода ограничений LLM будет предоставляться четкий шаблон кода (template), в который будет вставляться только тело метода.

## 4. Пошаговый план реализации (Action Plan)

* **Шаг 1: Структуры данных и хранение.** Создание структуры данных `SoftSkillDefinition` (модель для JSON) и менеджера `SoftSkillManager` (загрузка/сохранение в AppData).
* **Шаг 2: Адаптер и Компиляция.** Реализация `DynamicSkillAdapter : IRevitSkill`. Имплементация `CSharpCodeProvider` для компиляции кода из строки в исполняемый `Action<UIApplication, string>`.
* **Шаг 3: Навык генерации (Hard Skill).** Разработка встроенного навыка `CreateOrUpdateSoftSkillSkill`. Обучение его возвращать ошибки компиляции обратно в LLM, чтобы агент мог сам исправить свой код со второй попытки.
* **Шаг 4: Навык чтения (Hard Skill).** Разработка встроенного навыка `GetSoftSkillCodeSkill` для поддержки цикла редактирования.
* **Шаг 5: Обновление интерфейса (UI).** Добавление боковой панели (или списка) со списком навыков (Hard/Soft) и привязка ее к `_skills` с возможностью визуально различать типы навыков.
